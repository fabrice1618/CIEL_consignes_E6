## 2. rêgles

### 2.1 Hébergement et versionnage

- votre dossier est hébergé sur github (public ou privé)
- je ne relis que des fichiers markdown correctement versionnés dans github
- **je ne relis aucun fichier word ou ppt**

### 2.2 Formats

- le format de présentation est **Marp**
- les documents finaux docx et ppt sont générés à partir de vos fichiers markdown et mis en page à la main

### 2.3 Schémas

- vos schémas sont réalisés avec draw.io pour être modifiables
- les autres schémas en mermaid.js ou plantUML

### 2.4 Suivi des corrections

- les corrections seront consignées sur github issue

## 3. Conseils

- Attention aux IA !!! Utiliser un style de rédaction technique, précis, concis, et professionnel
- je peux vous fournir un prompt d'évaluation de vos présentations (si elles sont en markdown)

## 4. Check-list avant chaque rendu

- [ ] les fichiers sont en markdown et poussés (commit + push) sur github
- [ ] aucun fichier word ou ppt n'est déposé pour relecture
- [ ] les schémas sont en draw.io (sources modifiables) ou en mermaid.js / plantUML
- [ ] la présentation est au format Marp
- [ ] le style est technique, précis, concis et professionnel
- [ ] les corrections précédentes (github issue) sont traitées
